PRE-ALPHA · 0.8.0 ON MAIN · MIT

One control plane for your AI agents.

AgenticOps Control Tower keeps an inventory of every agent you run, the packages each one carries and the health it reports. It collects evidence from AgenticLens, Agentic Evals, Agentic Sidecar and Agentic Chaos, raises alerts when a run fails or evidence goes stale, and gates configuration changes and recovery behind a human approval.

THE PROBLEM

Agents multiply faster than anyone can track them.

Where is everything running?

Agents ship as Lambdas, containers and Kubernetes jobs across teams and environments, each with its own versions of tracing, evaluation and guard packages.

Which signal do I trust?

Traces, eval gates, guard decisions and chaos reports live in separate tools. Nobody sees the posture of one deployment across all of them.

Who approved that fix?

Configuration changes and recoveries happen out of band, with no preview, no second operator and no record of what was verified afterwards.

HOW IT WORKS

From heartbeat to verified recovery.

Health is what agents report. Evidence is what the ecosystem produced. Tower keeps both side by side and never lets one silently overwrite the other.

  1. 01

    Register

    Each agent registers its deployment, environment and installed packages.

  2. 02

    Report

    Agents send heartbeats; producers push native evidence artifacts.

  3. 03

    Detect

    Rules raise deduplicated alerts and open an incident view.

  4. 04

    Approve

    A preview is approved by a second operator with its own token.

  5. 05

    Verify

    The action runs, is verified, and lands in the audit trail.

Recovery execution covers one deterministic staging runtime today. Reusable runbooks are planned for 0.9. See limitations and the roadmap.

ECOSYSTEM

The operator view of DeepAgentLabs.

Each sibling package keeps its own logic. Tower reads their native artifacts, attributes them to a deployment and shows them together. None of them is required to run Tower.

AgenticLensTrace runs; failed runs raise lens.failed. Agentic EvalsEval reports and release-gate results in posture. Agentic SidecarGuard decisions and required escalations in posture. Agentic ChaosChaos experiment reports in posture. Deep Agentic Core MCPInvestigate incidents from an MCP host.

Versions tested together are listed in Tower 0.8 compatibility.

QUICK START

See a fleet in under a minute.

Install from the repository to get 0.8.0. The sample snapshot needs no server, token or account.

  • Base install needs only pydantic, packaging and jsonschema.
  • Add the api extra for the server, server-mode CLI and console.
  • pip install agenticops-control-tower currently installs 0.2.0, which predates snapshots, tokens and the console.
Full getting started Fleet snapshot use case
bash
git clone https://github.com/DeepAgentLabs/agenticops-control-tower.git
cd agenticops-control-tower
python -m venv .venv && source .venv/bin/activate
python -m pip install ".[api]"

agenticops-control-tower --snapshot examples/sample_fleet_snapshot.json status
agenticops-control-tower --snapshot examples/sample_fleet_snapshot.json capabilities list
agenticops-control-tower --snapshot examples/sample_fleet_snapshot.json posture
